# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue.

1. Open the repository where you found the issue.
2. Go to the **Security** tab and choose **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and its impact.

Only the maintainers can see the report. You will get an answer as soon as possible; Sanctuary is maintained by one person, so please allow a few days.

## Supported versions

Sanctuary has not published a stable release yet. Fixes go to the `main` branch of each repository.
